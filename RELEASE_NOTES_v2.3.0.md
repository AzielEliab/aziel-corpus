# Aziel Digital Library v2.3.0 — World Gazetteer

Adds a disk-backed world gazetteer integrated with the temporal-geospatial corpus map.

- One-click/CLI bulk download and local conversion from GeoNames.- Full and lite profiles.- Raw source retention plus SHA-256 receipts and verification.- Millions-scale on-disk lookup instead of loading global aliases into RAM.- Alternate/historic names with language, preferred/short/colloquial flags and from/to periods.- Conservative ambiguity handling; coordinates are never guessed.- Automatic date × place event pinning from resolved gazetteer mentions.- Gazetteer browser/search page and CLI commands.- Re-index command for applying a newly built gazetteer to an existing corpus.- Gazetteer health counters and source verification.
The runtime does not use GeoNames web-service APIs during normal operation.
