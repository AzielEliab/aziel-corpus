# iOS platform folder

This tree was authored without the Flutter SDK on PATH, so the Xcode
project is not generated here.

From the parent `mobile/` directory:

    flutter create --org com.azieeliab --project-name azielcorpus .

Then:

    flutter pub get
    flutter run

Offline. No analytics. Bundle id: `com.azieeliab.azielcorpus`.
